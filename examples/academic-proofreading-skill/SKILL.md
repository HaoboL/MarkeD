# Academic proofreading

1. Read the supplied passage and identify the requested audience and venue if given.
2. Correct grammar, ambiguous references, and inconsistent terminology.
3. Keep scientific facts, statistics, citation identifiers, and author intent intact.
4. Present the revision and briefly list substantive uncertainties for the author to verify.
